# Router 本地测试与分享链接

新分享链接使用 `https://llm-api-test.xiecq.top/#api=...&key=...&model=...`。
`api` 是完整的 Chat Completions 地址，`key` 是调用者的 API Key，`model` 是界面展示的测试模型；使用 URLSearchParams 编码一次。fragment 不随页面 HTTP 请求发给 GitHub Pages / CDN，但浏览器和页面 JavaScript 能读取，仍不可公开分享含 Key 的链接。

## 导入与存储

在挂载应用及恢复存储前读取参数并立即 replaceState 清理地址栏。兼容旧查询参数链接；fragment 有导入字段时整份采用 fragment，不与旧查询参数或已保存配置拼接。重复参数、无效协议、含控制字符或无法清理地址栏时，保留空的临时会话，不恢复任何旧 Key。

所有分享链接均进入临时模式：配置、Provider、历史、图片与文件句柄仅存当前页面内存；不读取、覆盖或删除原有浏览器数据。临时模式的重置、清空历史与自定义 Provider 编辑也不写持久存储。刷新或关闭后不恢复这次导入。顶端短提示说明临时模式和计费方式。

直接打开无导入参数的工具仍恢复/保存原有配置。模型历史只持久化连接和结果，不再保存完整 Key；历史中的请求凭证和 CSV 导出脱敏。原历史中的 Key 在正常加载该历史时脱敏，配置与测试记录保留。重载后应用历史配置需要重新填写 Key。

## 调用

取消配置变动后五秒自动探针。打开工具、导入链接、恢复配置、选择 Provider 或模型均不会自动发起模型调用。仅手动点击探针、开始测试，或用户明确启动的定时测试，才发起按正常用量收费的模型请求。模型目录的公开读取不是模型推理请求。

## Router 提示与上线

Router 首次简短确认：外部测试工具会临时读取账号级 Key；手动测试正常计费。用户可主动记住信任选择，按账号、Router 来源、目标域名和告知版本隔离，并可重置。确认偏好不包含 Key、登录凭证或完整测试链接。

先发布本项目，确认支持 fragment 的版本已上线，再发布 Router。旧测试站只读查询参数，不能识别新链接；不得为兼容而把 Key 自动降级到查询参数。两个仓库需分别提交/发布。

## 验证

`pnpm typecheck`、`pnpm test`、`pnpm build`。测试使用虚构凭证和内存 IndexedDB，验证参数编码、旧链接兼容、隔离、无自动调用、存储和导出脱敏。CI 在构建发布前执行类型检查和测试。不截图、不运行 UI/浏览器自动化、不发真实模型请求。
